# Создание замка без игры — 15_new_account.py

## Что делает
1. Сверяет подпись `FP 2064:` на 4 захваченных new_account (4/4 ок) и порядок полей (совпадает).
2. passport `new_account` (новый guid) → fpid + auth_token.
3. Через ~5 с: versionDiff2 + manifest → ak → AES-ключ.
4. Через 8–9 с от new_account: `init {kingdom_id:837, is_old_account:1}` → новый uid.
5. Через ~28–30 с: `token_login` + `init {kingdom_id:0}` (как перелогин игры).
6. Пишет `mitm/session_bundle_<uid>.json` (seq_next=1) → дальше 11_run_plan с idx 0 (туториал, включая jumpProphaseProcess).

По умолчанию DRY-RUN: в сеть не уходит ничего (даже проверка IP). Лог: `logs/new_account_dryrun.log`.

## Сеть / IP
- live только с `--proxy`; иначе отказ. `requests.Session(trust_env=False)`, HTTPS через CONNECT по имени хоста — DNS делает прокси. socks5:// запрещён (только socks5h://).
- Перед new_account, init и перелогином — проверка выходного IP той же цепочкой; не 203.0.113.20 → стоп.
- Ферма (fpid 182070973 / uid 71206420) — стоп при любом совпадении.
- getServersState НЕ шлётся: игра шлёт его из сессии фермы.

## Риск прямого IP в старых скриптах
- 10_send_cmd.py:230 `requests.post` без прокси → **прямой выход** (или env-прокси). 11_run_plan.py ходит через него → тоже риск.
- 12_login.py: без `--proxy` идёт напрямую, в live только предупреждение.
- mitm/inject.py: явный UPSTREAM — ок.
- Защита: `run_guarded.py --proxy http://127.0.0.1:18081 11_run_plan.py ...` (принудительный прокси + проверка IP, исходники не тронуты).

## Неизвестные
- gateway_name / gateway_finger_print / gateway_connid: в HTTP их нет (берутся из TCP-шлюза игры). Уйдут пустыми — примет ли сервер, неизвестно.
- Fp-Device-Token берётся из профиля 98566384 (игра обновляет его через devproxy) — может быть устаревшим.
- device_id, android_id, fp_device_id, origin_guid — те же, что у всех аккаунтов этого эмулятора (игра делает так же); guid новый.
- anon_id генерируется 12_login случайно на каждый init, time_zone +02:00, gaid пустой — в записи игры могут быть другие значения; это отличие от клиента.
