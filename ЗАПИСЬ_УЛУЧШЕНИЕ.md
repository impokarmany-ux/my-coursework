# ЗАПИСЬ: улучшение здания (City:upgradeObject)

## Откуда образцы
Полный круг `mitm\decrypted\`: запросы 1011, 1129, 1173–1280 (новый замок uid 98565609).
Связанные: 1191/1250 `City:addObject`, 1046/1133 `Item:useConsumableItem` (type=speedup), 1142 `city:freeSecondBuildingQueue`.

## Команда
Отправляется внутри `call:commit`, поле `op = "City:upgradeObject"`, нужен правильный `seq`.

```json
"args": {"gold":0, "c_job_id":0, "building_id":<id здания>, "city_id":<uid>, "instant":false, "auto":false}
```

| Поле | Что значит |
|---|---|
| building_id | id здания из `city_map` (маленькие 1,2,4… = стартовые, большие ~16xxxxxxxx = поставленные игроком). Это НЕ type_id |
| city_id | = uid (в JWT) |
| gold | сколько самоцветов доплатить. **Всегда 0** |
| instant | true = закончить сразу. **Всегда false** — в круге true бывает только в туториале, где сервер это делает бесплатно |
| auto | автоматическое улучшение. **false** |
| c_job_id | 0 (не связан с другой задачей) |

Уровень в запрос не кладётся — сервер сам берёт «текущий +1».

## Сравнение образцов
- 1011/1129: `instant:false` → в ответе `job` с таймером (event_type 30, queue "free").
- 1173…1280: `instant:true, gold:0` → в ответе сразу новый `level` (туториал, бесплатно).
- Меняются только `building_id` и `instant`; `gold` везде 0.

## Ответ (instant:false)
`data.set.job[0]`: job_id, time_start, time_end, `trace.next_level`, `trace.resource` (списано), `trace.items` (списанные предметы-материалы), `queue` ("free" = бесплатная очередь строителя).
`data.set.user_city[0].resource` — остаток ресурсов, `free_queue_job_id` — очередь занята.

## Что рядом (НЕ разрешено в скрипте)
- `Item:useConsumableItem` {job_id, item_id, amount, type:"speedup", …} — тратит ускорения.
- `city:freeSecondBuildingQueue` args=null — вторая очередь.
- `City:addObject` {slot_id, type, building_id(=timestamp), gold:0, instant:false, c_job_id} — постройка нового здания.

## Скрипт
В `10_send_cmd.py` команда в SAFE_WRITE_ALLOWLIST, но с охраной: отказ, если gold≠0, instant≠false, auto≠false или нет building_id.
```
python 10_send_cmd.py --session mitm/session_bundle.json --op City:upgradeObject --args "{...}" --allow-write
```
Перед отправкой проверь `free_queue_job_id == 0` через `Player loadBaseData`.
