| seq | op |

| 28 | City:upgradeObject (замок 4→5) |

| 37 | **City:upgradeObject instant** ← бесплатно building 2 |

Правила:
- Один писатель seq за раз. Скриптовый `call:commit` двигает серверный seq → клиент ловит **ok:98** / «ошибка соединения».
- После игры руками: перезахватить session + актуальный `seq_next` (= последний seq+1, здесь было бы **40**).
- После скрипта: релог игры или не трогать клиент, пока seq не синхронизирован.
- Ping / ttAck / firebaseAck / saveFunction* — **без** seq, на счётчик commit не влияют.
