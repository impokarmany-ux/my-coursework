# МИТМ — перехват HTTPS Guns of Glory (только окно netbot_test)

Дата: 2026-10-31 (Europe/Sofia)
Цель: увидеть команды игры (gog-global / gog-passport) открытым текстом через mitmproxy.

## Зачем это нужно

Раньше сырой tcpdump (gog1.pcap) показывал только TLS-шифротекст.
MITM садится посередине: игра ↔ mitmproxy ↔ сервер, и мы видим HTTP.

## Окружение

- Python 3.12.1, mitmproxy 12.2.3 уже стояли
- netbot_test = index 3, adb emulator-5560, Android 9, root
- Surfshark VPN был включён (tun1) — оставлен, не мешал
- Фермы (index 0/1/2) не трогали

## Шаги что сделала

1. Папка mitm\ + аддон dump_gog.py (пишет bodies для kingsgroup/gog).
2. CA hash subject_hash_old = c8750f0d.0 (через cryptography, openssl не было).
3. /dev/root строго RO → bind-mount: /data/local/tmp/cacerts_mitm → /system/etc/security/cacerts + chcon system_file.
4. mitmdump -p 8080 --listen-host 0.0.0.0 -s dump_gog.py -w flows.mitm
5. Хост для эмулятора LDPlayer = 172.16.1.2 (не 10.0.2.2). wget → 502 = порт жив.
6. settings put global http_proxy 172.16.1.2:8080 только в emulator-5560.
7. force-stop + monkey launch com.diandian.gog, ждали ~90с.

## Результат

### Вердикт: TLS MITM УСПЕШЕН. Pinning НЕТ.

Не было Certificate Verify Failed. Игра приняла наш CA.
mitmdump всё ещё крутится; стоп — см. ниже.

### Открытый текст

- Passport: POST https://gog-passport.kingsgroupgames.com/client_api.php
  method=token_login (также get_social_info); заголовки Authorization/Fp-Device-Token;
  ответ JSON с fpid/auth_token (в dumps токены = [REDACTED]).
- Bootstrap gog-global JSON:
  POST https://gog-global.kingsgroupgames.com/api/
  method=versionDiff2, затем method=manifest
  UA: UnityPlayer/2022.3.27f1 (UnityWebRequest/1.0, libcurl/8.5.0-DEV)
- Ещё открыто: devproxy (/decdevicetoken, /v3/cloudconf, /deviceprofile/v4),
  user-privacy, dw-fpcs, kg-logagent-gog, gog-news/community/achievement/store-coin,
  popups-api.funplus.com

### Второй слой шифрования

После versionDiff2+manifest почти все POST /api/ идут как
Content-Type: application/octet-stream (бинарное тело).
Счёт: 2 JSON + ~122 octet-stream на gog-global.
TLS снят, но поверх HTTPS есть прикладное шифрование (Cipher/маска/GData).
Дальше: один octet-stream из mitm\bodies\ + Ghidra.

### Стоп (вернуть окно в норму)

powershell -ExecutionPolicy Bypass -File E:\protocol_analysis\capture\mitm\STOP.ps1

Сбрасывает http_proxy, umount CA, убивает mitmdump. Фермы не трогает.
После ребута окна: rebind_ca.ps1 затем снова http_proxy.
